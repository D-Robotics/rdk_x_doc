# FAQ

## Common issues when first using the development board

- **<font color='Blue'>Board does not power on</font>**:
  - Make sure you are using the recommended power adapter.
  <DocScope versions=">=3.5.0" products="RDK X5">
  - Make sure the microSD card has been flashed with an Ubuntu system image.
  </DocScope>
  <DocScope versions=">=3.5.0" products="RDK X5 Module">
  - Make sure the microSD card or eMMC has been flashed with an Ubuntu system image.
  </DocScope>
- **<font color='Blue'>Hot-plugging the storage card during use</font>**: The development board does not support hot-plugging the microSD card. If this happens accidentally, restart the development board.

For more questions, see the [FAQ](../../08_FAQ/01_hardware_and_system.md) section, or visit the [D-Robotics Developer Forum](https://developer.d-robotics.cc/forum) for help.
